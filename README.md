# Brawl Stars Map Converter Discord Bot

Discord bot that converts any uploaded image.

## Installation

```bash
pip install disnake pillow numpy
```

## Usage

Send an image with:

```
k!convert
```

The bot generates `MAP_<image>.png` and sends it back.
